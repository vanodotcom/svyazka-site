# Связка: код страниц для Тильды

Сайт svyazkaclub.ru собран на Тильде. В каждом блоке T123 «HTML-код» стоит одна короткая строка, а сам код страницы лежит здесь, в папке `p/`. Исправленный файл появляется на сайте сам примерно через минуту, ничего перевставлять не нужно.

| Страница Тильды | Адрес | Файл |
|---|---|---|
| Шапка | — | p/header.html |
| Подвал | — | p/footer.html |
| Главная | / | p/home.html |
| Я здесь впервые | /start/ | p/start.html |
| Школы | /schools/ | p/schools.html |
| Записаться в школу | /schools/join/ | p/join.html |
| Походы | /hikes/ | p/hikes.html |
| Календарь | /calendar/ | p/calendar.html |
| Библиотека | /library/ | p/library.html |
| О клубе | /club/ | p/club.html |

Строка для блока T123 (вместо `home` имя файла без `.html`):

```html
<div data-sv="home"></div><script src="https://vanodotcom.github.io/svyazka-site/sv.js"></script>
```

## Как поправить текст самому

1. Откройте нужный файл в папке `p/` и нажмите карандаш «Edit».
2. Всё, что меняется руками, отмечено словом **ПРАВИТЬ**: новости и события на главной, походы, календарь, тексты школ, сезон набора.
3. «Commit changes». Через минуту-две обновите страницу сайта.

Фото, которые не загружены в Тильду, лежат в `img/`.
